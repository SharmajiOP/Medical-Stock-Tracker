# Medical Stock Tracker

A simple front-end project for managing medicine inventory and recording medicine requests in a clean dashboard interface.

## Overview

Medical Stock Tracker is a lightweight web application built with HTML, CSS, and JavaScript. It is designed to help monitor available medicines, highlight low-stock items, and log medicine requests submitted by employees.

## Features

- Dashboard cards for total medicines, low-stock items, total units, and request count
- Search bar to quickly filter medicines by name
- Inventory table with stock and expiry details
- Request form with basic validation
- Request log with employee name, medicine, quantity, reason, and timestamp
- Automatic stock update after each valid request
- Responsive layout for smaller screens

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.

No additional setup or installation is required.

## Use Case

This project is suitable as a basic stock tracking interface for clinics, office medical rooms, training demos, or academic front-end submissions.
